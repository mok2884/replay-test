# replay-test

生放送を録音し続け、言い間違いをすぐ聞き返して本線に出すソフト（`replay.py`）。
`replay_test.py` はデバイス確認用の小さなテストソフト。

## 入手
Actionsの最新のビルドから `Replay-windows` をダウンロードして展開し、`Replay.exe` を起動する。

## キーボード
| キー | 動き |
|---|---|
| アルファベット全部 | 今録音している位置にマークを打つ |
| `Shift`＋アルファベット | カーソルの位置にマークを打つ |
| `,` / `.` | 波形を縮小／拡大する |
| `↓` / `↑` | 前／次のマークに移り、マークの少し前から検聴する（秒数は設定で変更） |
| `←` / `→` | 2秒戻す／送って、すぐ検聴する |
| `Shift` | 押している間、検聴を等倍にする |
| `Space` | 検聴の再生／停止。止めた位置がスタンバイ位置 |
| `Enter` | ONLINE PLAY／STOP。検聴中はその瞬間の位置から等速で出す |
| `Esc` | 作業をやめて、録音の先端の表示に戻る |

本線に出している間は `Enter` 以外を受け付けない。録音は裏で続く。

## マウス
| 操作 | 動き |
|---|---|
| 波形か目盛りをクリック | そこへ飛ぶ。止まっていれば飛ぶだけ、再生中なら続ける |
| `Ctrl`+ホイール（波形の上） | 時間軸の拡大・縮小 |
| `Shift`+ホイール（波形の上） | 波形の縦の拡大・縮小 |

## 保存
設定した保存先に、番組全体を1つのWAV（16bit・モノラル）で保存する。録音を止めて再開しても同じファイルに直接つながる。
マークの時刻は同じ名前の `.marks.txt` に残る。

## メモリ
録音全体をメモリに持つので、48kHzで1時間あたり約0.35GB使う。
