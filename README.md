# replay-test

Windows PCでの起動、デバイス認識、Enterから音が出るまでの速さを確かめるテストソフト。

## 使い方
1. Actionsの最新のビルドから `ReplayTest-windows` をダウンロードして展開する。
2. `ReplayTest.exe` を起動する。
3. 入出力デバイスを選び、Enterを押す。1kHzのテスト音（-20dBFS、1秒）が出る。Escで止まる。
4. 「結果をコピー」で、デバイス一覧と測定結果をコピーできる。

## 表示される遅延について
「Enterから音まで」は、ソフト内の処理時間とデバイスが申告する出力遅延の合計で、目安の値。
キーボードの反応やデバイスの実際の遅延は含まれないことがあるので、正確な値は実測で確かめる。

## 注意
- ASIOは、入力と出力に同じデバイスを選ぶ。
- テスト音は放送系につながない状態で試す。
