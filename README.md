# ボコーダー（vocoderブランチ）

しゃべった声を、鍵盤で決めた音程の声に変えるソフト（`vocoder.py`）。

## キーボード
| キー | 動き |
|---|---|
| `A` `S` `D` `F` `G` `H` `J` `K` `L`（白鍵）、`W` `E` `T` `Y` `U` `O` `P`（黒鍵） | 押している間、その音程になる |
| `1`〜`8` | 登録したコードを出す |
| `Space` | キープ。押している音を保持する。もう一度で解除 |
| `Z` / `X` | 鍵盤のオクターブを下げる／上げる |
| `Esc` | 全部止める |

キープ中に別の鍵盤やコードを押すと、保持している音が置き換わる。
コードボタンを右クリックすると、鳴らしている音を登録できる。
