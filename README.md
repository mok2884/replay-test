# ボコーダー（vocoderブランチ）

しゃべった声を、鍵盤で決めた音程の声に変えるソフト（`vocoder.py`）。

## キーボード
| キー | 動き |
|---|---|
| `A` `S` `D` `F` `G` `H` `J` `K` `L`（白鍵）、`W` `E` `T` `Y` `U` `O` `P`（黒鍵） | 押している間、その音程になる |
| `1`〜`8` | 登録したコードを出す |
| `Space` | HOLD。その後に押した鍵盤を全部保持する。もう一度か `Esc` で解除 |
| `Z` / `X` | 鍵盤のオクターブを下げる／上げる |
| `Esc` | 全部止める |

HOLD中は、同じ鍵盤をもう一度押すとその音だけ外れる。コードを押すと丸ごと置き換わる。
コードボタンを右クリックすると、鳴らしている音を登録できる。

## EQ
4バンドのパラメトリックEQ。グラフの点をドラッグするか、`FREQ` `GAIN` `Q` のつまみで調整する。ゲインが0のバンドとオフのときは計算しない。
